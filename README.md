# Photo Stocktake (写真の棚卸しアプリ)

Photo Stocktake は、スマートフォン内の写真を定期的に確認し、不要な写真の削除や必要な写真の保管を促す Android アプリケーションです。  
写真の整理を後回しにしないよう、毎日決まった時間に通知を行い、写真ごとに直感的な操作で整理を行えます。

---

## 📱 アプリ概要・基本方針

- **初回起動以降の写真を自動管理**: アプリを初めて起動した時点以降に追加された写真を管理対象とします。
- **毎日22:00の整理通知**: 未整理の写真がある場合、毎日指定された時刻（22:00）に通知でリマインドします。
- **完全ローカル管理**: 写真データや管理情報はすべて端末内に保存され、外部サーバーやクラウドへの送信・自動アップロードは一切行いません。
- **誤削除の防止**: 写真削除時は Android OS 標準の削除確認画面（`MediaStore.createDeleteRequest`）を経由し、誤操作を防ぎます。
- **連写写真の自動グループ化**: 撮影日時が近い写真（2秒以内）を連写候補としてまとめ、一括削除や個別保管を行えます。

## 🛠 機能仕様

### 1. 写真の整理・状態管理

写真は以下の4つの状態を持ち、端末内（`SharedPreferences`）に保存・維持されます：

| 状態 | 意味・動作 |
|---|---|
| **未整理 (PENDING)** | まだ整理判断が行われていない新しい写真。棚卸しの対象となります。 |
| **保管 (KEPT)** | ユーザーが「残す」を選択した写真。以降の整理対象から除外されます。 |
| **再確認待ち (SNOOZED)** | 「明日確認」または「日時指定」で設定された写真。指定日時が来るまで保留されます。 |
| **削除済み (DELETED)** | ユーザーが削除を承認し、端末から削除された写真。 |

### 2. 写真ごとの操作

写真プレビュー上に重ねて表示される操作ボタンから以下の処理を実行できます：

| 操作ボタン | 仕様・動作 |
|---|---|
| **残す** | 写真を整理対象から除外（`KEPT`）します。設定済みの再確認通知も解除されます。 |
| **明日確認** | 翌日の 22:00 に再確認対象（`SNOOZED`）として通知を予約します。 |
| **日時指定** | 日付・時刻ピッカー（`DatePicker` / `TimePicker`）を起動し、任意の日時に再確認対象として設定します。 |
| **削除** | 確認の上、OSの安全な削除要求画面を起動して写真を削除します。 |

### 3. 連写写真のグループ化

- 撮影日時が **2秒以内** の複数の写真を連写候補として自動グループ化します。
- グループ代表写真を参考にしながら、各写真を個別に「残す」選択をしたり、「グループ全体を削除」ボタンからまとめて削除できます。

### 4. 毎日の通知 ＆ 再確認通知

- **日次通知**: 毎日 22:00 に未整理（または再確認期限が来た）写真の枚数を通知します。
- **個別再確認通知**: 写真ごとに指定された日時に再確認リマインドを通知します。
- **端末再起動対応**: 端末再起動（`BOOT_COMPLETED`）時にアラームおよび個別予約通知を自動再スケジューリングします。

## 🏗 アーキテクチャ ＆ 設計方針

単体テスト（Unit Test）が容易で、保守性の高いレイヤードアーキテクチャ（MVVM + Repository パターン）を採用しています。

```
com.example.photostocktake
├── model/                  # 純粋なデータモデル (PhotoItem, PhotoStatus)
├── domain/                 # 100% Android非依存のビジネスロジック (BurstGroupingUseCase, SnoozeCalculator)
├── data/                   # データソース抽象化・リポジトリ (PhotoRepository, MediaStore, SharedPreferences)
├── scheduler/              # アラーム・通知スケジューラー (NotificationScheduler, AlarmManager)
├── ui/                     # Jetpack Compose UI ＆ ViewModel (PhotoViewModel, PhotoScreen, PhotoRow)
└── MainActivity.kt         # 権限要求・OS確認ダイアログ管理を行う薄い Activity
```

### 技術スタック

- **プラットフォーム**: Android
- **開発言語**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **非同期処理・状態管理**: Coroutines, StateFlow, ViewModel (`androidx.lifecycle`)
- **システム連携**: MediaStore API (Android 11+ Delete Request), AlarmManager, NotificationChannel
- **テスト**: JUnit 4 (日本語記述テスト)
